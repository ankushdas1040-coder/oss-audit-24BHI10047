## ⚙️ Shell Scripts Overview

### 🔹 Script 1 — System Identity Report
Displays system information such as:
- Linux distribution
- Kernel version
- Logged-in user
- Uptime and date
- License information

---

### 🔹 Script 2 — FOSS Package Inspector
- Checks if a package is installed
- Displays version and details
- Uses a case statement to describe the package

---

### 🔹 Script 3 — Disk and Permission Auditor
- Scans important directories
- Displays:
  - Disk usage
  - Permissions
  - Owner/group details

---

### 🔹 Script 4 — Log File Analyzer
- Reads a log file
- Counts occurrences of a keyword (default: "error")
- Displays last 5 matching lines

---

### 🔹 Script 5 — Open Source Manifesto Generator
- Takes user input
- Generates a personalized open-source philosophy
- Saves output to a `.txt` file
